# Power BI Data Professional Survey Dashboard
An interactive Power BI dashboard analysing data professional survey results, including salaries, programming languages, job roles and work-life balance.

## Analysis
The dashboard analyses survey data on job roles, salaries, programming languages, location, work-life balance, salary satisfaction and the difficulty of breaking into data.

## Skills Demonstrated
* Data cleaning and transformation
* Power Query
* Data visualisation
* Filters and navigation
